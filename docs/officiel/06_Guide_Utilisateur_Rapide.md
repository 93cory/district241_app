# GUIDE UTILISATEUR RAPIDE

## PNPI — Plateforme Nationale du Pilotage Industriel

---

### CONNEXION

1. Ouvrez **https://pnpi-gabon.ga** dans votre navigateur
2. Entrez votre identifiant et mot de passe
3. Si la 2FA est activee, entrez le code a 6 chiffres de votre application d'authentification
4. Vous etes redirige automatiquement vers votre espace selon votre role

### ROLES ET ESPACES

| Role | Page d'accueil | Actions principales |
|------|---------------|---------------------|
| **Ministre** | Dashboard ministeriel | Consulter les KPIs, briefings, decisions strategiques |
| **Directeur** | Dashboard PNPI | Superviser, valider, deleguer, benchmarker |
| **Instructeur** | Mes Dossiers | Instruire les ATI, commenter, decider |
| **Inspecteur** | Mon espace | Inspections terrain, rapports, heatmap |
| **Operateur** | Mon espace (Guichet) | Soumettre ATI, suivre, renouveler |
| **Admin** | Administration | Gerer utilisateurs, monitoring, securite |

### SOUMETTRE UN ATI (Operateur)

1. Allez dans **Mon espace**
2. Cliquez **Soumettre un ATI**
3. (Optionnel) Cliquez **Utiliser un modele pre-rempli** pour gagner du temps
4. Remplissez le formulaire : secteur, type d'activite, observations
5. Cliquez **Soumettre**
6. Suivez votre dossier dans **Mes ATI** — le compteur SLA indique le temps restant

### INSTRUIRE UN ATI (Instructeur)

1. Allez dans **Mes Dossiers** ou **Kanban**
2. Selectionnez un ATI prioritaire (file de triage)
3. Consultez :
   - La **Checklist de conformite** (generez-la si elle n'existe pas)
   - Le **Scoring de risque** (evaluation automatique)
   - La **Recommandation IA** (approuver/rejeter/approfondir)
4. Ajoutez des **commentaires** (publics ou internes)
5. Cliquez le bouton de **transition** pour changer le statut
