# PLAN DE DEPLOIEMENT ET BUDGET

## Deploiement national de la PNPI

---

### PHASE 1 — PILOTE (Semaines 1-4)

**Objectif** : Valider la plateforme avec un groupe restreint

| Action | Semaine | Responsable |
|--------|---------|-------------|
| Installation serveurs + SSL | S1 | Equipe technique |
| Configuration base de donnees production | S1 | Equipe technique |
| Migration donnees existantes | S1-S2 | Equipe technique + Ministere |
| Formation administrateurs (2 personnes) | S2 | Concepteur |
| Formation instructeurs pilotes (5 personnes) | S2-S3 | Concepteur |
| Onboarding 10 operateurs pilotes | S3 | Instructeurs formes |
| Tests et corrections | S3-S4 | Tous |
| Bilan pilote | S4 | Direction |

**Budget Phase 1 : 12 000 000 FCFA**

### PHASE 2 — EXTENSION (Semaines 5-12)

**Objectif** : Deployer sur 3 provinces prioritaires (Estuaire, Haut-Ogooue, Ogooue-Maritime)

| Action | Semaine | Detail |
|--------|---------|--------|
| Formation inspecteurs terrain (10) | S5-S6 | App mobile + geofencing |
| Deploiement 3 provinces | S5-S8 | 50+ operateurs |
| Integration email/SMS | S7-S8 | Notifications automatiques |
| Formation direction (ministre + directeurs) | S9 | Dashboard + briefing |
| Audit securite externe | S10 | Test penetration |
| Bilan intermediaire | S12 | Ajustements |

**Budget Phase 2 : 15 000 000 FCFA**

### PHASE 3 — NATIONAL (Semaines 13-24)

**Objectif** : Couverture complete des 9 provinces

| Action | Semaine | Detail |
|--------|---------|--------|
| Extension 6 provinces restantes | S13-S18 | Tous operateurs |
| Integration douanes (DGDI) | S15-S18 | API verification NIF |
| Integration impots (DGI) | S18-S20 | API conformite fiscale |
| Deploiement monitoring Grafana | S20 | Performance temps reel |
| Formation e-learning ouverte | S22 | 5 modules interactifs |
| Ceremonie de lancement officiel | S24 | Communication nationale |

**Budget Phase 3 : 14 000 000 FCFA**

### LIVRABLES

A l'issue du deploiement, le Ministere disposera de :

1. Plateforme PNPI complete et operationnelle
2. Documentation technique et utilisateur
3. 50+ agents formes
4. Donnees migrees et verifiees
5. Integrations avec les systemes partenaires (douanes, impots)
6. Monitoring et alertes automatiques
7. Sauvegardes automatiques quotidiennes
8. Plan de continuite d'activite (PRA/PCA)
