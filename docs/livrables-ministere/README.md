## Règle de mise à jour

Chaque nouveau domaine métier du Livre Blanc doit être intégré dans :

1. la matrice FAM ;
2. le dossier exécutif si sa valeur est ministérielle ;
3. le PPT si le message doit être présenté ;
4. le cahier des charges si le domaine devient une exigence ;
5. le prototype si une démonstration est utile.
