# PNPI — Pack logo recommandé

Version : 30 juillet 2026

## Choix recommandé

Pour la présentation ministérielle, utiliser le logo actuel / institutionnel du PNPI plutôt que les visuels 3D.

Raison :

- fond clair et lisible ;
- plus sobre pour un dossier officiel ;
- meilleure tenue en impression ;
- moins d’effet “marketing” ;
- utilisable dans Word, PDF, PowerPoint et l’application.

## Fichiers

| Fichier | Usage |
|---|---|
| `pnpi-logo-horizontal.svg` | en-têtes, couverture claire, slide claire |
| `pnpi-logo-horizontal-dark.svg` | couverture sombre, slide d’ouverture |
| `pnpi-logo-mark-officiel.svg` | icône, favicon, pastille, petit marquage |

## Règles simples

1. Utiliser le logo horizontal sur les couvertures et les documents.
2. Utiliser la marque seule uniquement quand l’espace est réduit.
3. Éviter les effets 3D dans les documents officiels.
4. Ne pas déformer le logo.
5. Garder une marge blanche autour du logo.

## Usage recommandé pour la présentation

- Slide 1 : `pnpi-logo-horizontal-dark.svg` ou logo texte blanc sur fond bleu nuit.
- Slides internes : `pnpi-logo-horizontal.svg` en petit dans le coin ou uniquement la marque.
- Documents Word/PDF : `pnpi-logo-horizontal.svg`.
- Application : conserver le logo actuel pour ne pas perturber l’identité déjà visible.
